# BN & Co Construction

Dark-luxury construction landing page for BN & Co Construction — built to capture quote enquiries.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Framer Motion
- React Hook Form

## Setup

```bash
npm install
cp .env.example .env.local
# Set NEXT_PUBLIC_FORM_WEBHOOK to your n8n webhook URL
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Homepage (hero, trust bar, about, services, projects, process, testimonials, quote form)
- `/projects` — Full project portfolio grid

## Deployment

Deploy to Vercel. Add `NEXT_PUBLIC_FORM_WEBHOOK` in project environment variables.
